## Code and environment changes

`BackendConfig` provides one `BACKEND_URL` setting for screening/video requests,
live WebSockets and error images. The current URL is also the fallback for this
development run. Use `--dart-define` for a new tunnel rather than editing multiple
screens.

The existing Python environment had conflicting package versions. It now uses
scikit-learn 1.6.1 to match the saved screening model, MediaPipe 0.10.21,
NumPy 1.26.4 and OpenCV contrib 4.11.0.86. These versions are recorded in
`backend/requirements.txt`. Model files and inference logic were not changed.

## Start another run

Run the backend from the repository root in one terminal:

```powershell
cd C:\Users\maste\Haemophilia
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

Start a tunnel in a second terminal, then copy the HTTPS URL it prints:

```powershell
C:\cloudflared\cloudflared.exe tunnel --url http://127.0.0.1:8000 --no-autoupdate
```

Run Flutter in a third terminal, replacing the example URL with the new URL:

```powershell
cd C:\Users\maste\Haemophilia\haemophilia_app
flutter run -d 625624b1 --dart-define=BACKEND_URL=https://YOUR-NEW-URL.trycloudflare.com
```
