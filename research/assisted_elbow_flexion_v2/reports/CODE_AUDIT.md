# Existing code audit — before Phase 1 training

The audit preceded writing this independent pipeline. Existing code and all canonical data remain unchanged. The user's 2026-10-04 Phase 1 training authorization is copied into `provenance/phase1_user_authorization.txt`; the archived release's earlier `training_authorized: false` remains historical evidence and is not edited.

All old normalized arrays are historical only. In particular, 104 reviewed ranges changed and their older representations are stale. Even an unchanged old range is freshly processed in this experiment.

MediaPipe's installed `Pose.process` docstring describes world landmarks as meters, centered between hips. These are monocular model estimates, not calibrated motion-capture measurements. Image landmarks are also retained to permit audit; features use estimated world xyz. World elbow angles and ratios avoid mixing normalized image x/y with differently scaled depth. The shoulder-depth and torso-lean measures are view-sensitive proxies, not clinical rotation or compensation diagnoses.

Original source SHA-256 is the immutable grouping key. Tracking state is reset at gaps between canonical frame unions; overlapping reviewed ranges can share freshly inferred frames within their source, and all such repetitions stay together in every fold. No excluded candidate becomes an example. Source decoding outside canonical ranges is needed to preserve original frame indices but those frames are not passed to pose inference.

Reproducibility records include fixed config/folds, source and timing hashes, raw arrays, resized-frame digest, decoder command/log, MediaPipe model asset hashes, software versions, and a 32-frame independent-graph repeatability check per source. Repeatability is verified on this environment; cross-platform bitwise equivalence is not assumed.
