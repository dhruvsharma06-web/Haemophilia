# Session workflow and exercise release — 7 October 2026

## Delivered

- Every unfinished assigned, active, paused or in-progress session expires one hour after its original scheduled start. Resuming does not reset the clock. Older longer windows are capped at one hour.
- Patients see a deadline/countdown. Expired work is unavailable on the active dashboard and appears in Expired sessions. A live assessment stops on expiry or doctor cancellation.
- Doctors can cancel unfinished current sessions and upcoming schedules. Assignment, recording, schedule and archive changes are atomic; recorded repetitions remain preserved and queued updates cannot restart ended work.
- The trained assisted-elbow V5 option is the only assisted-elbow exercise in the catalogue. V2 remains in source/model files. Its V6 controller now exposes measured feedback, stages, arm, angle range, range of motion, timing, angular speed, smoothness, return completion, descriptive movement control and annotated review frames when available.
- Elbow flexion and extension uses the supplied V4 LSTM and exact 30-frame/22-feature input contract. V3 remains in files. Provenance is in `models/elbow_v4_provenance.json`.
- Session reports/history expose feedback and measured statistics for both doctor and patient. Missing values are not replaced with fabricated scores. Practice data and previews are not stored as clinical sessions.
- Previous uncommitted workflow work is included: account validation/approval handling, assigned-session availability, dashboard sections, support/message attribution, cleaner login copy, localization, notification inbox/bell and smoother wireframe rendering.
